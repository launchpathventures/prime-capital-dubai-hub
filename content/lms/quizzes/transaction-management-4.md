## Questions

### Question 1
**After you add deal details on a won deal, what must you do for them to be kept?**

A) Nothing, they save as you type  
B) Press Save changes in the bar at the bottom  
C) Send a message to the admin team  
D) Close the deal page  

**Correct Answer:** B  
**Explanation:** Changes are only kept when you press Save changes in the bar that appears at the bottom of the page.

---

### Question 2
**What does the status word 'Later' mean on a row?**

A) It was rejected  
B) You can skip it forever  
C) It is not needed yet; it is needed when the deal closes  
D) The admin team will add it  

**Correct Answer:** C  
**Explanation:** Later items are needed at closing. Add them when you have them.

---

### Question 3
**When everything your part needs is in, what happens?**

A) You press Send to admin  
B) The file is sent to your admin team by itself  
C) Nothing until your manager asks  
D) The deal is closed  

**Correct Answer:** B  
**Explanation:** There is no send button. The list says the file has been sent to your admin team.

---

### Question 4
**Your manager asks for a new copy of a passport and gives a reason. What do you do?**

A) Message the new copy to the manager  
B) Open the deal and add the new copy on the same row  
C) Delete the deal and start again  
D) Wait for the admin team to chase you  

**Correct Answer:** B  
**Explanation:** Add the new copy using the same row's button. It replaces the old one and the old one is kept in the history.

---

### Question 5
**An older deal asks 'What kind of deal is this?' and you are not sure. What is best?**

A) Pick the shortest list  
B) Pick Rental  
C) Ask your manager before choosing  
D) Leave it for the admin team  

**Correct Answer:** C  
**Explanation:** The deal type decides which documents are asked for, so do not guess.
